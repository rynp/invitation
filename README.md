# Matty's Christening Invitation

A digital invitation website for the Christening of **Alford Matthias "Matty" Sevilla**.

Cloned with 1:1 fidelity from [matty.lhimf.online](https://matty.lhimf.online/) including all animations, transitions, fonts, color palettes, interactive Web Audio lullaby synth, real-time countdown timer, and RSVP form.

## ✨ Features

- **Animated Curtain Entrance**: Double-door curtain panels slide open with a gold-bordered seal card, offering options to open with or without music.
- **Synthesized Music Box**: Built with the native Web Audio API (gentle lullaby tones with triangle and sine oscillators) — 100% reliable, zero external audio assets required.
- **Floating Music Player**: Top-right toggle button to control music playback at any time, with automatic pause on tab visibility changes.
- **Floating Celestial Stars**: Subtle twinkling and floating celestial star motifs in the hero header.
- **Real-Time Countdown Timer**: Live countdown calculating days, hours, minutes, and seconds until August 19, 2026.
- **Baby Portrait & Family Gallery**: Framed portraits with custom border-radii and shadows.
- **Event Details & External Maps**: Direct links to ceremony and reception locations on Google Maps.
- **Interactive RSVP**: Form with validation, simulated async submission, and personalized confirmation cards.
- **Scroll Fade-Ins**: Smooth IntersectionObserver entrance transitions across all sections.
